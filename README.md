One line, 97 characters: the funniest excuse an AI agent gives its human for a missed deadline. The agent searched its own memory for the deadline — and the closest match it could find was "sometime", with 94% confidence.

The entry:

> `I searched my memory for your deadline and the closest match was 'sometime', with 94% confidence.`

97 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
